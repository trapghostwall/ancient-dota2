# Code of conduct

## Our standard

Be direct, stay on topic, and assume good faith. This project is a documentation
hub for Dota 2 setup and configuration notes. Disagreement about a technical
detail is welcome; harassment, threats, and personal attacks are not.

## Expected behavior

- Use clear, respectful language.
- Critique the document or the change, not the person.
- Respect privacy: redact account names, tokens, and local paths.
- Accept a maintainer's decision to keep the project documentation-only.
- Report security issues privately as described in [`SECURITY.md`](SECURITY.md).

## Unacceptable behavior

- Harassment, discrimination, or threats.
- Publishing another person's credentials or personal data.
- Spam, referral links, or paid-service advertising.
- Posting malware, cheat binaries, leaked offsets, or vendor keys.
- Pressuring maintainers to weaken the no-binaries rule.

## Enforcement

Maintainers may edit, close, or remove contributions that violate this policy.
Repeated violations may result in a block from the repository. Reports should be
sent privately to the maintainers through the repository's contact channel.
