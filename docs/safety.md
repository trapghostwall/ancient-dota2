# Safety and limitations

Ancient is an independent documentation hub. It does not contain a loader,
DLL, executable, cheat source, game offsets, or anti-cheat bypass.

## Account risk

Third-party software can violate Valve's terms and lead to a VAC or game ban.
No documentation page can guarantee otherwise. If you choose to use an external
package, use an account you are willing to lose and accept the risk yourself.

## What this hub does not provide

- No DLL, EXE, loader, injector, or packed binary.
- No game offsets, signatures, or memory-layout data.
- No anti-cheat bypass, spoofing, or detection-evasion instructions.
- No license keys, accounts, or credentials.
- No guarantee that an external download is available, safe, or current.
- No warranty of fitness for a particular purpose.

## Download hygiene

1. Use the linked folder only.
2. Avoid mirrors, shorteners, and direct-message attachments.
3. Verify the archive password and checksum when available.
4. Scan the archive before unpacking.
5. Do not disable security software to make a download work.
6. Do not run an unsigned binary as administrator without a concrete reason.

## Reporting a problem

When opening an issue, include:

- the documentation page you followed;
- the exact step that failed;
- the game build and Windows version;
- the tool version, if an external tool is involved;
- a redacted error message or screenshot.

Do not include passwords, tokens, Steam Guard codes, or personal account data.

## Availability

The repository and the external folder are independent. A documentation page
can remain online while a download disappears, or the reverse. If the folder is
unavailable, open a documentation issue instead of trusting a reupload.
