# Preview disclaimer

The images in `assets/` are original SVG interface and map concepts created for
this documentation hub. They are not screenshots, game captures, or evidence
that a particular feature exists in a current build.

## What the previews show

- `assets/preview-menu.svg` shows a compact match panel with cooldown, rune, and
  draft groups. It illustrates information hierarchy and spacing.
- `assets/preview-visuals.svg` shows a stylized map with rune, ward, and
  objective timing callouts. It illustrates a visual language, not real match
  data.
- `assets/banner.svg`, `assets/logo.svg`, and `assets/download-button.svg` are
  brand artwork for the repository.

## What the previews do not show

- No real player names, match IDs, or account data.
- No game memory, offsets, signatures, or anti-cheat behavior.
- No guarantee that an external package looks or behaves this way.
- No claim of affiliation with Valve or any vendor.

## Reusing the artwork

The SVGs are part of this repository and are covered by the MIT license unless a
file says otherwise. If you reuse them, keep the "concept" framing and do not
present them as game captures.
