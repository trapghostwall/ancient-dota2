# FAQ

## Does this repository contain a cheat?

No. It is a documentation-only community hub. It contains setup notes,
configuration guidance, interface concepts, and links to an external folder. It
does not contain cheat source, a loader, a DLL, or an executable.

## Does it contain a DLL or EXE?

No. The repository is intentionally documentation and SVG artwork only. The
validation workflow rejects common binary extensions.

## Is this affiliated with Valve?

No. Ancient is an independent, unofficial project. Dota 2 and Valve are
trademarks of Valve Corporation.

## Will using third-party software get me banned?

It can. Valve's terms and anti-cheat systems are outside this project's control.
No page here can guarantee safety. Read [Safety](safety.md) before using any
external package.

## Does the linked download work on the current Dota 2 build?

This hub does not ship or test the external package. The download folder is the
only distribution point referenced here. Check the folder and the vendor notes
for the current build; do not assume that an old package still works.

## Why is there no source code?

Because this is a documentation hub, not a software release. The repository
deliberately avoids shipping game-specific code, offsets, or binaries.

## Can I contribute a preview or a guide?

Yes. Read [`CONTRIBUTING.md`](../CONTRIBUTING.md). Documentation, original SVG
artwork, and reproducible troubleshooting notes are welcome. Binaries, leaked
offsets, vendor keys, and account data are not.

## How do I update the documentation?

Pull the latest commit, keep your local notes, and open an issue for anything
that is stale. There is no auto-updater in this repository.
